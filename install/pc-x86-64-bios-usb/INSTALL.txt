Eve OS — bootable USB for a PC (x86_64, BIOS / legacy)
======================================================

You flash **`utm/eve-bios.img`** onto a USB stick (whole disk). That image uses
**MBR + boot sector** (legacy PC boot), same layout as QEMU without OVMF — for PCs
that boot with **CSM / “Legacy USB”** or very old firmware without UEFI.

1) Build the BIOS disk image (release)
--------------------------------------
From the Eve repo root (nightly Rust + `x86_64-unknown-none` as in rust-toolchain):

     ./scripts/sync-x86-bios-img.sh

  or full workspace build:

     ./scripts/build-all-images.sh

  Confirm the file exists:

     ls -la utm/eve-bios.img

  If it is missing, run `cargo build --release -p eve-os` and check for errors;
  `build.rs` must produce `bios.img` under `target/.../out/`.

2) Identify the USB drive (whole disk, not a partition)
-------------------------------------------------------
**Linux:** `lsblk` — use `/dev/sdX` (whole disk, not `sdb1`). Unmount any mounted
partitions on that disk first.

**macOS:** `diskutil list` — external USB disk, e.g. `/dev/disk3` (not `disk3s1`).

3) Write the image (erases the entire USB)
------------------------------------------
From the repo root, as **root**:

     sudo ./scripts/x86-usb-write.sh --bios /dev/sdX        # Linux example
     sudo ./scripts/x86-usb-write.sh --bios /dev/disk3      # macOS example

Omitting `--bios` is the same as `--bios` (BIOS is the default mode).

Type **YES** when prompted. On macOS the script prefers **`rdiskN`** for speed.

4) Boot the PC
--------------
- Eject the USB safely, plug it into the target machine.
- In firmware: **enable legacy / CSM** and **USB–HDD** or **USB legacy boot** if
  your menu separates “UEFI: USB” from “USB” / “Hard disk”.
- Open the **boot menu** (F12, F10, Esc, etc.) and pick the USB / removable /
  legacy entry (wording varies by OEM).
- **Secure Boot** is usually irrelevant for pure BIOS chain load; UEFI-only
  machines should use **`utm/eve-uefi.img`** instead — see
  `install/pc-x86-64-uefi-usb/INSTALL.txt`.

5) Expectations
---------------
- Brief blank screen until the framebuffer comes up is normal.
- PS/2 or USB HID depends on firmware and Eve; VirtIO is for QEMU, not bare metal.

See also: `utm/X86-USB-BOOT.txt`, `utm/BUILT-IMAGES.txt`, `./scripts/print-eve-paths.sh`
